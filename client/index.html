Бэкап конфига роутера (sysupgrade)

Создаст архив /tmp/backup.tar.gz с конфигурацией роутера и скачает его.

Рекомендации по пакетам мониторинга

Для мониторинга трафика рекомендуем nlbwmon — официальный пакет OpenWrt, потребляет минимум ресурсов (~200KB RAM).

opkg update opkg install nlbwmon /etc/init.d/nlbwmon enable /etc/init.d/nlbwmon start

WireGuard — управление туннелями

Для 1000+ роутеров используйте подсеть 10.10.0.0/16 — 65 534 адреса. Каждый роутер получает фиксированный IP при подключении.

⚠️ Управление WireGuard пирами будет реализовано в следующей версии. Настройте WireGuard вручную на сервере, затем укажите WG-IP роутеров в их карточках.
# Установить WireGuard на роутер: opkg update opkg install wireguard-tools kmod-wireguard # Адресация для флота: # Сервер (панель): 10.10.0.1/16 # Роутер 1: 10.10.0.2/32 # Роутер 2: 10.10.0.3/32 # ... # Роутер 1000: 10.10.3.234/32

Параметры агента

Установка агента на роутер

Выполните на роутере через SSH:

wget http://СЕРВЕР:3000/agent/install.sh -O - | sh

Или с явным адресом:

NETCTRL_SERVER=http://СЕРВЕР:3000 \ wget http://СЕРВЕР:3000/agent/install.sh -O - | sh

Бэкап базы данных

База данных SQLite содержит все роутеры, метрики, снапшоты и настройки. Рекомендуем делать бэкап еженедельно.

🗃 Автобэкап через cron на хосте
Добавьте в crontab на хост-машине (запускать еженедельно по воскресеньям в 03:00):
0 3 * * 0 docker exec netctrl sh -c "cp /app/data/netctrl.db /app/data/netctrl_$(date +\%Y\%m\%d).db" && docker cp netctrl:/app/data/netctrl_$(date +\%Y\%m\%d).db ~/backups/
⚠ При docker compose down -v данные сохранятся только если volume примонтирован к ./data
